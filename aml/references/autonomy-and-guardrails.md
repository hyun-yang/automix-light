# 맡기기와 안전망

Claude 에게 얼마나 맡길지는 "믿음"의 문제가 아니라 **되돌릴 수 있느냐**의 문제다.

## 언제 맡겨도 되나

네 가지가 모두 맞으면 하나씩 확인하지 말고 끝까지 맡겨도 된다.

1. **작은 변경** — task.md 의 그 구간 `위험` 이 "낮음"이다.
2. **되돌릴 수 있다** — git 저장소이고, 직전까지의 작업이 커밋돼 있다.
3. **확인할 방법이 있다** — 테스트가 있거나, 눈으로 볼 화면이 있다(task.md 의 `증명`).
4. **안전망이 켜져 있다** — `/aml:doctor` 가 "안전망 켜짐"이라고 말한다.

하나라도 아니면 한 걸음씩 간다. 특히 **되돌릴 수 없는 일**(돈이 나감, 남에게 메일이 감, 서버에 올림)은 규모와 상관없이 늘 사람이 확인한다.

Claude Code 에서 실제로 맡기는 방법은 두 가지다. `/aml:go` 에게 "이 구간은 끝까지 맡길게요"라고 말하거나, 편집 승인을 매번 묻지 않는 모드로 바꾸는 것이다(Claude Code 입력창에서 `shift+tab` 을 눌러 모드를 바꾼다). 맡긴 뒤에는 결과를 반드시 본다 — 맡긴다는 건 안 본다는 뜻이 아니라, **중간이 아니라 끝에서 본다**는 뜻이다.

## aml 안전망이 막는 세 가지

`spec.md` 와 `task.md` 가 있는 폴더에서만 동작한다. 다른 저장소에는 아무 영향이 없다.

| 막는 것 | 왜 | 정말 해야 한다면 |
|---|---|---|
| `.env` 를 저장소에 넣기 | 비밀번호·API 키가 한 번 들어가면 지워도 기록에 남는다 | `.gitignore` 에 `.env` 를 넣고, 값은 파일에 직접 적는다 |
| 버그 고치는 중 테스트 파일 수정 | 테스트를 고치면 버그가 아니라 확인이 사라진다 | 테스트 자체가 잘못됐을 때만 `rm .aml/FIXING` 후 진행 |
| 강제 푸시 · 하드 리셋 · 통째로 지우기 | 되돌릴 수 없다 | 사용자가 직접 터미널에서 실행한다 |

막힐 때는 항상 **왜 막았는지와 어떻게 하면 되는지**가 함께 나온다. 그냥 "거부됨"으로 끝나지 않는다.

끄고 싶으면 `.aml/config.yaml` 에:

```yaml
guard: "off"
```

권하지 않는다. 이 세 가지는 초보자가 하루를 통째로 날리는 대표적인 방법이다.

## 규칙 카드와 안전망은 다르다

- **규칙 카드**(`.claude/skills/`) — "이렇게 해 주세요". 대개 지켜지지만, 100%는 아니다. 판단이 필요한 것에 쓴다.
- **안전망**(훅) — "이건 못 합니다". 매번, 예외 없이 막는다. 판단이 필요 없는 것, 일어나면 되돌릴 수 없는 것에 쓴다.

반드시 지켜져야 하는 규칙은 둘 다 만든다. 규칙 카드가 실수를 드물게 만들고, 안전망이 나머지를 막는다.

## 내 프로젝트에만 안전망 추가하기

`.claude/settings.json` 에 훅을 등록하고, 스크립트에서 종료 코드 2 로 막는다.

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          { "type": "command",
            "command": "bash ${CLAUDE_PROJECT_DIR}/.claude/hooks/my-guard.sh" }
        ]
      }
    ]
  }
}
```

```bash
#!/usr/bin/env bash
# .claude/hooks/my-guard.sh — 예: 실제 서버에 올리는 명령은 사람이 직접 하게 한다
CMD=$(cat | python3 -c 'import json,sys; print(json.load(sys.stdin).get("tool_input",{}).get("command",""))' 2>/dev/null)
if echo "$CMD" | grep -q "deploy --prod"; then
  echo "실제 서버 배포는 직접 실행해 주세요. (지금 올릴 내용을 먼저 확인하세요)" >&2
  exit 2      # 2 = 막음. 이 메시지가 Claude 에게 그대로 전달된다.
fi
exit 0
```

세 가지만 기억하면 된다. **종료 코드 0 = 통과, 2 = 막음**, 그리고 **막을 때는 이유와 방법을 함께 말한다**. 어떤 일이 있어도 스크립트가 오류로 죽으면 그냥 통과되게 만든다 — 안전망이 작업을 못 하게 만드는 게 더 나쁘다.

더 자세한 설정은 공식 문서: `code.claude.com/docs/en/hooks-guide`, `code.claude.com/docs/en/settings`.
