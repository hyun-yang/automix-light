## 화면과 설명 기능

Chrome과 Playwright로 화면을 열고 캡처를 직접 살펴봤다. 설명 위로 마우스를 옮겨도 설명이 유지되고, Esc·같은 단어 다시 누르기·바깥 누르기로 닫혔다. 모든 용어 설명을 세 화면 너비에서 각각 열어 화면 안에 표시되는지 확인했다. axe의 WCAG A·AA 자동 검사에서 지적 0, 화면 실행 오류 0이었다.

검사 도구와 캡처는 제작 환경의 `/tmp/aml-manual-browser/`에만 두었다. 매뉴얼을 읽는 데 필요하지 않으며 임시 파일이라 지워질 수 있다.

## 확인 범위의 한계

Chrome에서 확인했다. Safari·Firefox와 실제 휴대폰 기기에서는 확인하지 않았으며, 터치는 브라우저의 모의 환경을 사용했다. 실제 초보자를 대상으로 이해도를 관찰하는 사용성 확인은 하지 않았다. 자동 접근성 검사 통과가 모든 사람이 불편 없이 읽는다는 보장은 아니다.
