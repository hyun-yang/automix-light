# 개별 매뉴얼 계획 — 언어 전환 링크 제거

상태: 2026-10-22 `$aml:go`로 두 HTML에 반영하고 개별 파일 기준으로 확인했다. 자세한 결과는 [확인 기록](verification.md)에 남겼다. 아래는 변경 범위를 정한 계획 기록이다.

## 원하는 결과

한글판과 영문판은 각각 열어 읽는 개별 파일이다. 매뉴얼에서 다른 언어판으로 이동하도록 안내하지 않는다.

## 삭제할 것

| 파일 | 현재 있는 언어 전환 링크 | 바꿀 내용 |
|---|---|---|
| automix-light-manual.html | 상단 오른쪽 English → automix-light-manual-en.html | 링크 제거 |
| automix-light-manual-en.html | 상단 오른쪽 한국어 → automix-light-manual.html | 링크 제거 |

- 두 HTML 전체에서 언어 전환 링크를 조사했으며, 현재 다른 위치에는 없다. 적용할 때도 링크 목적지와 문구를 함께 다시 확인한다.
- 언어 전환 전용 `.language-link` 화면 스타일과 해당 링크의 언어 연결 속성도 정리한다.
- 각 문서의 `lang="ko"`·`lang="en"`은 문서의 언어를 읽는 데 필요한 정보이므로 유지한다.

## 범위

- 두 HTML 안에서 다른 언어 매뉴얼로 가는 링크를 없앤다.
- README로 가는 설치·저장소 안내 링크, README에서 각 매뉴얼로 들어가는 링크는 유지한다.
- 제목·설명 내용·명령·SDLC 표·용어 설명의 내용 변경은 포함하지 않는다.
- 과거 작업의 확인 기록은 남기고, 새 확인 기록에 “이제 언어 전환 없이 각각 사용하는 파일”이라고 명시한다.

## 확인할 것

1. 두 HTML 전체에 언어 전환 링크와 전용 스타일이 남지 않는다.
2. 360·768·1280px에서 상단의 로고와 탐색 링크가 자연스럽게 배치되고 잘리지 않는다.
3. 각 파일을 따로 열어도 도움말·SDLC 표·용어 설명이 작동하고, 인터넷 없이 본문을 읽을 수 있다.
4. 기존 임시 확인 도구의 “두 언어 이동 성공” 조건을 개별 파일 확인으로 바꾼다. HTML 언어 표시와 영어 번역의 한국어 잔여 확인도 언어 선택 링크 예외 없이 검사한다.
5. AGENTS.md의 확인 방법과 REVIEW.md의 기준으로 검토하고 manual/verification.md에 결과와 확인하지 못한 범위를 기록한다.
