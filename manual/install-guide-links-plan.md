# 설치 안내 링크 변경 계획

상태: 계획. HTML은 아직 수정하지 않았다. `$aml:go`로 적용한다.

## 지정 주소

- 한글판: https://github.com/hyun-yang/automix-light#%EC%96%B4%EB%8A%90-%EB%8F%84%EA%B5%AC%EC%97%90%EC%84%9C-%EC%93%B0%EB%82%98%EC%9A%94
- 영문판: https://github.com/hyun-yang/automix-light-en#which-tool-do-you-use

한글 주소에서 줄바꿈된 `automix-`와 `light`는 이어 붙인다. 각 주소의 `#` 뒤 제목 위치는 사용자 지정 그대로 쓴다.

## 바꿀 곳

| 위치 | 한글판 문구 | 영문판 변경 후 문구 |
|---|---|---|
| 상단 | 설치 안내 보기 | See the repository guide |
| 다른 도구 도움말 | 저장소의 설치 안내 | repository's installation guide |
| 하단 | 저장소 안내 | repository guide |

- 각 언어의 세 링크를 모두 위 지정 주소로 통일한다. 사용자가 이 범위를 선택했다.
- 영문판의 “(Korean)” 3곳을 모두 제거한다. 주변 문장의 마침표는 유지한다.
- GitHub 안내를 보려면 인터넷 연결이 필요하다는 점을 명확히 표시한다.
- 두 매뉴얼은 계속 개별 HTML 파일이다. 서로 이동하는 언어 전환 링크는 만들지 않는다.

## 확인할 것

1. 두 언어의 링크 목적지 3개씩이 지정 주소와 정확히 일치하고, URL 안에 공백·줄바꿈이 없다.
2. 두 HTML에서 기존 `../README.md` 안내 링크가 없고 영문판에 “(Korean)”이 남지 않는다.
3. 링크를 선택하면 지정한 주소로 이동을 요청하는지 확인한다. 원격 페이지의 접근 가능 여부를 실제로 확인하지 않았다면 접근 성공이라고 기록하지 않는다.
4. 설치 안내는 인터넷이 필요하지만 본문·그림·도움말·용어 설명은 오프라인에서 계속 사용할 수 있다.
5. 작은 화면에서 문구가 잘리지 않고 기존 도움말과 개별 파일 조건이 유지되는지 확인한다. 기존 검사와 검토 결과를 manual/verification.md에 기록한다.

## 걱정되는 것

없음. 사용자 지정 URL을 그대로 사용한다. 원격 저장소의 공개 상태나 권한은 이번 변경에서 다루지 않는다.
