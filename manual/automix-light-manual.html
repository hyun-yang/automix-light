독립 확인

별도 확인 도우미가 새로 살펴봐요. 실제로 따로 맡겼을 때만 독립 확인이라고 기록해요.

Claude Code 판은 별도 확인 도우미를 부르는 절차가 있어요. Copilot CLI 판도 별도 도우미를 부르며, 실제로 맡기지 못하면 자체 확인으로 기록해요. 어느 방식이든 “무엇을 실행해서 확인했는지”를 함께 보세요.

위험한 작업을 막는 장치도 도구마다 달라요. Claude Code·Copilot CLI 판에는 AML의 일부 작업 차단 장치가 있고, Codex 판에는 같은 AML 전용 장치가 없어요. Codex 자체의 권한·승인 설정은 환경에 따라 적용돼요. Copilot의 차단 장치도 제한 시간을 넘으면 차단하지 못할 수 있어요. 모든 도구가 같은 보호를 보장하지는 않아요.

중간에 막히거나 멈췄어요. 뭐라고 말하면 좋을까요?
  • 낯선 설명이 많을 때개발을 처음 해 봐요. 쉬운 말로, 한 가지씩 알려 주세요.
  • 무엇을 골라야 할지 모를 때잘 모르겠어요. 제 상황에 맞는 방법과 이유를 추천해 주세요.
  • 멈춘 이유를 모를 때지금 어디에서 멈췄는지, 제가 해야 할 일이 있는지 알려 주세요.
  • 새 대화에서 이어 하고 싶을 때같은 프로젝트의 계획과 진행 기록을 읽고, 남은 일을 알려 주세요.

같은 작업 폴더에서 계획과 기록을 확인한 뒤 $aml:go로 이어 갈 수 있어요. 중간에 중요한 선택을 묻는다면, 이유를 읽고 답해 주세요.
