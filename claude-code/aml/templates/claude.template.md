## 지도는 어디에 있나

- `intent.md` — 원래 왜 만들기로 했는지 (최신이 맨 위)
- `spec.md` — 무엇을 만드는지와 완성 기준 (이 목록이 진짜 기준)
- `task.md` — 순서대로 할 일 + 구간별 계획(바뀌는 파일 / 위험 / 증명)
- `progress.md` — 한 일 기록 (최신이 맨 위)
- `REVIEW.md` — 리뷰할 때 무엇을 보는지

작업은 `/aml:go`, 점검은 `/aml:review`, 진행 상황은 `/aml:status`, 다음 바퀴는 `/aml:next`.
